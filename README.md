# Лист — демонстрационный сайт кофейни

Одностраничный сайт на HTML, CSS и JavaScript. Не требует сборки или платного хостинга.

## Запуск

Откройте `index.html` в браузере. Для просмотра изменений обновляйте страницу.

## Что изменить под своё кафе

- Название, тексты и позиции меню — в `index.html`.
- Цвета и оформление — в `styles.css`.
- Фото первого экрана — `assets/cafe-hero.png`.
- Перед публикацией добавьте реальные адрес, часы работы и контакты, если они нужны.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub.
2. Загрузите в него содержимое этой папки (файлы должны лежать в корне репозитория).
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажмите **Save**.
5. После публикации сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Страница использует локальные пути к файлам, поэтому работает и в корне, и по адресу проекта GitHub Pages.
